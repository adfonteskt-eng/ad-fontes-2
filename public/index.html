          Sources & licenses

          "Back to the sources" means every claim here traces to something you can click. This page lists exactly what powers each part of ad fontes, and under what license — nothing here is generated or guessed by the AI; it's a fixed description of the underlying data and tools.

          Bible translations

          YouVersion Platform API — the Berean Standard Bible, King James Version, World English Bible, and American Standard Version, fetched live by reference and displayed under YouVersion's Platform Terms of Use. Never cached into a searchable index (see Full-text search below for why that's a separate, independently-sourced copy).

          Original-language text, lexicons & cross-references

          STEPBible-Data, created by STEPBible.org based on work at Tyndale House, Cambridge — CC BY 4.0. Backs the word-by-word Greek/Hebrew interlinear (Strong's numbers, transliteration, morphology), the lexicon search, and word-occurrence lookups. Parsed and re-formatted for display (word-by-word tables, keyword search over the lexicon glosses) — the underlying tagged text itself is unmodified from the source files.

          Full-text search

          The Berean Standard Bible's own full text, dedicated to the public domain (CC0) by its translation committee and fetched directly from its own distributor — deliberately not derived from the YouVersion API copy above, even though BSB is also one of the translations shown on-screen (see the README's Full-text search section for the licensing reasoning).

          Commentary

          Matthew Henry (Concise), Barnes' Notes, Jamieson-Fausset-Brown, Gill's Exposition, and the Geneva Study Bible — all public domain, fetched live per verse from biblehub.com. Always shown in its own clearly labeled block, separate from the AI's own words.

          Cross-reference diagrams

          openbible.info's cross-reference dataset — CC BY 4.0, ~345,000 verse-pair connections drawn primarily from the public-domain Treasury of Scripture Knowledge, each with a relevance score. A real, curated dataset someone else compiled — not a list of connections the AI thought of on its own.

          Map diagrams

          Place coordinates from openbible.info's Bible-Geocoding-Data (CC BY 4.0), each with a real, source-backed confidence score — a place is only ever marked "disputed" or "identified" based on that dataset's own evidence, never a guess. Base map coastline from Natural Earth (public domain, no attribution required).

          The AI model

          Claude (Anthropic) writes the conversational reply, decides which of the tools above to call for a given question, and never generates Bible text from its own memory — every verse shown to you comes verbatim from the sources above, by reference. Any text a reply presents as a direct quotation is additionally checked against the real, fetched translation text for that turn and flagged if it doesn't match (see the "Quote verified" note under a reply) — see Receipts Mode for exactly what that check does and doesn't prove.
